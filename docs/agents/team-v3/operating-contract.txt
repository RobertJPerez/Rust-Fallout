RESOURCE SCHEDULING
Set CARGO_TARGET_DIR to the assigned private target. Run from assigned worktree:
py -3 G:\Rust-Fallout\tools\team-build.py --lane LANE --session UUID --slot focused -- COMMAND ARGUMENTS
Cargo command is powershell -NoProfile -ExecutionPolicy Bypass -File
G:\Rust-Fallout\tools\cargo.ps1 with --locked, normally --jobs 2 (or one under
observed memory pressure). Preserve command exit and logs in a new local directory.
Use --slot heavy for full workspace checks, native corpus proofs, GPU operations
and original-game captures. Heavy admission is automatic, not coordinator-granted.
Every build/proof owns a separate target/native directory; never overwrite binaries
or source inputs of a live proof. Avoid nesting wrappers; the outer heavy operation
owns its subprocess builds and honors the same job bound.
Coordinator launches frozen-proof orchestration from its assigned integration
tree, passing the frozen repository and new private proof target explicitly to
the child builder/verifier. It must not point that child at integration's live
target. This permits review commits on the same integration branch while the
separate proof source and binaries remain immutable.
Default acquisition is nonblocking: exit75 means resource busy and no child ran.
Do another bounded task and retry at its boundary; do not poll a busy slot every
few seconds. --wait is available when the result is genuinely the only next step;
it checks STOP/authorization frequently and cannot count as productive coding.
At most two focused operations and one heavy operation total, as limited by
current control.json. The second focused slot was enabled after measured resource
headroom and Windows containment tests; use jobs1 during cold build waves.
Reduce capacity when measured memory/CPU pressure requires it. Do not increase
it merely because more agents are configured.
The v3 wrapper requires exact run/session identity throughout the command and
contains its own child process tree. See tool tests for demonstrated guarantees.

reuse. Independently test engineering choices; do not infer retail timing, units,
numeric coercion, default actor state or condition truth. No successful no-ops.

When Robert says stop, append a current-run stop_requested row with his instruction

mark stopped, archive/release own lease and return. If Robert explicitly gives a
graceful deadline, finish only that current safe boundary within the deadline.
No queued task, build, upload or persistent Goal overrides STOP. Resume requires
Robert's instruction and a fresh reconciled run. Historical stop messages remain.
