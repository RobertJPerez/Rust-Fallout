`execution::reference_literal::stage(&World, &PreparedSources, &Content,
Selection, Limits)` admits the existing journal head, exactly Begin/one

An SCRO literal uses the source resolver's exact content key, explicit null or
runtime player dependency. SCRV requires an actual reference declaration and
compatible initialized canonical storage. Live identity remains `ReferenceId`
throughout; no identity passes through `Number`. The explicit player is required
when the source resolver requires it. Missing, deleted or unavailable content,
absent indices, uninitialized values and unknown live IDs cannot become null.
Resolved content must pass the current nondeleted source form lookup.

The stage owns a historical trace and a private existing `StagedEventChanges`.
Dropping it has no effects; consuming commit revalidates epoch, source cohort,
revision and journal head. One successful commit assigns one typed value,
increments revision once and acknowledges precisely that head. It registers no
reference and changes no inventory, placement, context, clocks or other locals.
Neither trace nor serialized report can authorize a later commit.

version strings. Fixed source/reference extents are charged first; remaining

bounds, not peak allocator or wall-clock guarantees.
