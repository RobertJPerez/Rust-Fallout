# Exact CELL region source declarations

`fallout cell-region-sources --install <root> --load-order <ordered.json> --cell <Plugin.esm:hex>` is the owned source consumer. Optional `--index-cache <private-cache>` reuses the existing strict source-bound header index. The JSON report exposes the exact ordered receipt and occurrence/element/resolved/unavailable header counts, with behavior and region effects unevaluated. Exit zero means the source closure was prepared, including explicit empty, absent, null or unavailable entries. A factory refusal emits a null source receipt and error with exit one; earlier strict source-index failures return the original error without manufacturing JSON authority.

`world::regions::CellRegionSources::load(&mut RecordStore, &FormKey, Limits)` seals one exact winning, live NV CELL and its complete ordered plugin cohort. The request is a private immutable Arc; reports cannot reconstruct authority. Borrowed `receipt`, `root`, `identity` and `validate_sources` expose inspection and strict reuse checks.

Each physical XCLR occurrence remains in disk order, including empty arrays and repeated occurrences. Each four-byte element retains its zero-based array ordinal, raw word, canonical REGN dependency, status and actual winning target header/source digest. Repeated elements remain repeated. Target bodies and behavior stay unknown; a resolved expected-kind live header establishes header source availability only. Absent fields, empty arrays, null words, missing targets, deleted winners and wrong-kind winners remain distinct. No older target or parent/default fallback is selected.

Receipts retain physical and visitor field ordinals, decoded field/element spans, full raw framing including a validated XXXX prefix, stored body provenance, and physical offsets only for uncompressed bodies. The existing strict importer, subrecord visitor, CELL decoder, canonical resolver and full source receipts are reused. Non-word tails, malformed frames, missing masters, failed canonical resolution, tainted CELL bodies, deleted/wrong-kind roots and changed cohort refuse the whole request. The existing resolver's source-backed noncanonical self-selector rule remains valid: a high byte beyond the declared masters selects the current source plugin, never its runtime load-order slot.

Nine independent lowerable ceilings precharge array rows, key metadata, raw frames and header witnesses before allocation or copying: 256 sources, 4097 record witnesses, 65536 physical fields, 256 occurrences, 4096 elements/source links, 4 MiB record bytes, 4 MiB read bytes, 1 MiB retained raw framing and 32 MiB metadata. Per-element repeated header witnesses count separately; target bodies are not read. Exact/one-under bounds and retry identity are tested.

Those callbacks do not authorize rewriting disk membership. This consumer applies neither sorting nor editor filtering/repair, and evaluates no region containment, geometry, priorities, weather, sounds, grasses, objects, inherited membership, runtime activation or retail parity.
